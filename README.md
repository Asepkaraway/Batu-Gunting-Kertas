# Batu Gunting Kertas

Game sederhana Batu Gunting Kertas untuk Python.

## Cara Menjalankan

1. Buka terminal di folder project.
2. Jalankan:
   ```
   python main.py
   ```

## Kontrol

- Ketik `B` untuk Batu
- Ketik `G` untuk Gunting
- Ketik `K` untuk Kertas
- Ketik `Q` untuk keluar

## Fitur

- Pilihan pemain melawan komputer acak
- Menentukan pemenang sesuai aturan klasik
- Menampilkan statistik kemenangan, kekalahan, dan seri

## Versi GUI (Pygame)

Jika ingin menjalankan versi dengan antarmuka grafis menggunakan Pygame, jalankan:

```
python gui.py
```

Catatan: Pastikan Pygame sudah terinstal di environment Python Anda. Install dengan:

```
pip install pygame
```
