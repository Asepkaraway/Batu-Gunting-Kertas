Perencanaan BGK (Batu Gunting Kertas)
=======================================

1. Tujuan Proyek
----------------
- Membuat game interaktif Batu Gunting Kertas yang berjalan di Python.
- Menyediakan antarmuka sederhana untuk bermain melawan komputer.
- Menyimpan skor pemain dan menampilkan hasil setiap ronde.

2. Fitur Utama
--------------
- Pilihan pemain: Batu, Gunting, Kertas.
- Pilihan komputer secara acak.
- Penentuan pemenang sesuai aturan klasik:
  - Batu mengalahkan Gunting
  - Gunting mengalahkan Kertas
  - Kertas mengalahkan Batu
- Tampilan hasil ronde dan statistik singkat.
- Menampilkan jumlah kemenangan, kekalahan, dan seri.
- Opsi ulang main dan keluar.

3. Arsitektur dan Struktur Folder
---------------------------------
Folder `Batu Gunting Kertas` akan berisi:
- `main.py` : entry point game.
- `perencanaan_BGK.txt` : dokumen perencanaan.
- `README.md` : ringkasan cara menjalankan.
- `assets/` (opsional) : ikon atau sumber daya jika dibutuhkan.

4. Teknologi
------------
- Python 3.x
- Pygame (opsional jika ingin GUI)
- Atau terminal input/output sederhana jika ingin versi minimal.

5. Rencana Implementasi
-----------------------
A. Versi Terminal Sederhana
- Buat menu awal.
- Masukkan pilihan pemain.
- Pilihan komputer dihasilkan acak.
- Tentukan hasil ronde dan tampilkan.
- Update skor dan tampilkan statistik.
- Tawarkan opsi lanjut atau keluar.

B. Versi GUI (opsional)
- Gunakan Pygame untuk membuat jendela.
- Tampilkan tombol untuk Batu, Gunting, dan Kertas.
- Tampilkan hasil dan skor di layar.
- Tambahkan animasi sederhana atau suara jika ingin.

6. Pembagian Tugas
------------------
- [ ] Buat file `main.py` dengan logika game.
- [ ] Buat tampilan menu dan input pengguna.
- [ ] Tambahkan fungsi validasi pilihan.
- [ ] Tambahkan fungsi skor dan statistik.
- [ ] Tambahkan opsi ulang main / keluar.
- [ ] Uji game di lingkungan Windows.

7. Prioritas Pengembangan
-------------------------
1. Game berjalan dengan input keyboard di terminal.
2. Logika aturan pemenang bekerja benar.
3. Skor dan replay berfungsi.
4. Jika selesai, kembangkan UI Pygame.

8. Catatan Tambahan
-------------------
- Pastikan file `highscore.txt` ditangani jika diperlukan untuk menyimpan skor.
- Gunakan penamaan variabel yang jelas.
- Pisahkan logika permainan dari tampilan jika memungkinkan.
